# src/drama_interaction/validation/repair.py 内容规划

- 状态：规划中（未实现）
- 上游依据：ADR-014 / 015、PRD §11 / §13

## 职责与边界

- 候选(candidate)级失败处理的两阶段实现：安全程序修复（确定性）→ 定向退回原 生成专家(Specialist)（大语言模型(LLM)，只修该条）→ 仍失败上抛 人工介入(HITL)。
- 明确不做（PRD §11 禁止项）：重新扫描整集、重新寻找新互动点、修改其他成功候选、重跑整个 生成专家(Specialist)、重跑上游 证据(Evidence)；不做节点编排（循环结构在 graph/nodes.py）。

## 依赖关系

- 依赖 validation/rules.py（错误分类与白名单）、specialists/base.py（单条修复入口）、llm.py（退回重生成的调用）、schemas/candidate.py。
- 被依赖方：graph/nodes.py（分支内校验-修复循环调用本模块）。
- LangGraph 分工：分支内循环（修复→再校验）的图结构表达在 nodes/builder；本模块只提供循环体内的业务步骤。

## 主要组成

- 阶段一：安全程序修复（纯确定性）
  - 输入：失败 候选(candidate) + 结构化错误；只在错误被 rules.py 标记为「可程序修复」时尝试。
  - 「安全」的界定：只做不改变业务语义、不引入新事实、不移动 锚点(Anchor)的规范化操作。
  - 可安全修复示例清单：
    - 文本首尾空白与多余空行清理。
    - 选项列表去重后仍满足数量约束。
    - 重复 候选(candidate)的机械去重（保留策略明确时）。
    - 明显的格式归一（全半角空格）。
    - 丢弃生成侧毫秒字段并置空（延时投票(deferred_vote)的 reveal_time / reveal_delay——渲染环节会重算，不改变业务语义）。
  - 不可安全修复（必须退回 大语言模型(LLM)或 人工介入(HITL)）清单：改写任何业务文本（题干(question) / 选项 / 金句台词(keyline)）、增删改变含义的选项、调整 锚点(Anchor)指向、补充缺失引用、修改 answer_id。
  - 修复后必须重新过全部 rules（不是只复查失败那条），通过才算修复成功。
- 阶段二：定向退回原 生成专家(Specialist)（大语言模型(LLM)）
  - 退回上下文构造：原 候选(candidate)全文 + 结构化错误（期望 / 实际）+ 必要局部 证据(Evidence)（触发(trigger)窗口与引用 片段(segment)的文本，而非整集）。
  - 调用原类型模块的单条修复入口（base.py 提供），只重新生成该条 候选(candidate)。
  - 重试次数上限：默认 1 次（产品需求文档(PRD)未定数值，见待定项）；重试产出再次过全部 rules。
- 人工介入(HITL)上抛：两次失败（程序修复 + 定向退回）后构造 人工介入(HITL)事件——候选(candidate)、全部错误历史、已尝试的修复记录、局部 证据(Evidence)——写入待人工队列，分支状态置「待人工」（PRD §13 触发条件第一条）。
- 全程记录：每次修复尝试的输入输出与结果留存（供 状态(State)持久化、可观测性(observability)与 基准评测(benchmark)的鲁棒性评估）。

## 关键设计点

- 程序修复的「安全」由白名单机制保证：rules.py 标记 + repair.py 白名单双确认，任何不在白名单内的操作拒绝执行——防止「顺手修一下」演变成无声的语义篡改。
- 修复不产生新事实：程序修复只能做规范化，凡涉及内容的改变都属于退回 大语言模型(LLM)的范畴。
- 定向退回的成本受控：上下文只带局部 证据(Evidence)，重试上限默认 1 次——单条失败的代价是常数级的。
- 成功候选零影响：本模块的所有操作只接收并返回单条 候选(candidate)，接口上就不可能触碰其他候选。

## 待定项

- 定向退回的重试次数上限（建议 1，产品需求文档(PRD)/架构决策记录(ADR)未定数值）。
- 程序修复白名单的最终清单（与 rules.py 联合冻结）。
- 人工介入(HITL)事件的数据结构细节（待 graph/state.py 的待人工队列定义对齐）。

## 测试要点

- 程序修复完全离线测试：白名单内错误被正确修复且再校验通过；白名单外错误被拒绝执行。
- 定向退回用假 大语言模型(LLM)测试：上下文构造完整性（原 候选(candidate) + 错误 + 局部 证据(Evidence)）、只返回单条、重试上限行为、失败后 人工介入(HITL)事件内容完整。
- 禁止项回归：任何 接口(API)形态都不接受「整集」「其他候选(candidate)」输入。
