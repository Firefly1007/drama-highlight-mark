# src/drama_interaction/scheduling/semantic.py 内容规划

- 状态：规划中（未实现）
- 上游依据：ADR-018、PRD §15.3 / §13 / §20.2 / §20.3

## 职责与边界

- 语义调度器(Semantic Scheduler)：仅在出现真实语义取舍时调用大语言模型(LLM)，从确定性约束筛出的待取舍集合中选择保留者。
- 明确不做：不重新寻找互动点、不重新分析完整一集（PRD §15.3）；不做确定性约束判断；不输出概率(probability) / 置信度(confidence) / 评分(score)。
  - 确定性约束判断属 constraints.py 职责。
  - 输出是离散候选标识(candidate IDs)，不输出概率(probability) / 置信度(confidence) / 评分(score)。
- 调度器提示词(Scheduler Prompt)属暂缓(Deferred)（PRD §22 第 7 项）：本层只冻结提示词(prompt)需覆盖的要素与调用协议。

## 依赖关系

- 依赖 scheduling/constraints.py、llm.py、schemas。
  - constraints.py：待取舍集合的来源，终检的复用处。
  - llm.py：调用。
  - schemas：候选与证据(Evidence)。
- 被依赖方：graph/nodes.py（semantic 节点调用）、人工介入(HITL)（无法返回合法选择时上抛）。

## 主要组成

- 触发条件形式化：constraints.py 产出的待取舍集合（冲突组非单成员、间隔 / 冷却(cooldown)互斥对、超预算(budget)）非空时才调用；确定性可解的情形（如组内只剩一个合法者）不经大语言模型(LLM)直接通过。
- 调用输入组装（PRD §15.3 五要素）：
  - 待选择候选(candidate)（含类型、载荷(payload)、锚点，及渲染产物中的真实 `show_at` / `duration_ms`）：因渲染已提前到池(Pool)之后，候选带真实毫秒，大语言模型(LLM)判断「挨太近」比看 `window_id` 直观，属改善。
  - 每个候选对应的局部证据(Evidence)（只渲染候选引用的窗口与片段(segment)，不传整集）。
  - 已选择互动的简要概况（已定候选的类型、时刻、一句话内容）。
  - 剩余预算(budget)。
  - 明确硬约束（必须保留数量上限、互斥关系声明）。
- 输出协议与合法性验证：模型只返回保留的候选标识(candidate IDs)列表；程序验证——标识(IDs)必须是待选集合的子集、数量不超过允许保留数；非法输出允许一次重试(Retry)（附违规说明），再失败上抛人工介入(HITL)（PRD §13 第四类触发）。
- 决策记录：每次调用留存输入摘要、模型返回、keep / drop 结果与理由（若模型给出）——供可观测性(observability)（PRD §20.2）与基准评测(benchmark)的调度质量评估。
- 提示词(prompt)要素方向（不写成文）：角色定位（调度取舍者而非分析者）、输入说明、离散标识(ID)输出格式、取向声明（互动价值、剧情覆盖、类型多样性的权衡原则）、禁止输出分数。

## 关键设计点

- 调用成本受控（PRD §20.3）：输入只带候选引用的局部窗口，一集至多次调用（冲突组数 + 预算(budget)超限情形），不做全候选重排。
- 大语言模型(LLM)的权力边界：只能从待选集合中挑选，不能新增、修改、重排锚点——终检（constraints.py）会拒绝一切违反确定性约束的输出。
- 非法输出的处理是「有限次重试(Retry) + 人工介入(HITL)兜底」，不是无限重试(Retry)也不是静默裁剪——保持失败透明。
- 与 constraints 的职责切分清晰：constraints 说「不能同时出现」，semantic 说「留哪个」，constraints 终检说「你选的我验收」。

## 待定项

- 调度器提示词(Scheduler Prompt)最终 wording（暂缓(Deferred)，PRD §22 第 7 项）。
- 多个冲突组是否合并为一次调用（减少调用次数）还是逐组调用（上下文更小更聚焦）：倾向逐组，待基准评测(benchmark)观察调用成本后定。
- 「已选择互动概况」的粒度（仅类型+时刻，还是含内容摘要）。
- 非法输出重试(Retry)次数上限（建议 1 次）。
- 观测项：调度器(Scheduler)输入带真实毫秒后，观测大语言模型(LLM)是否试图输出时刻或做时间算术——时刻是输入不是输出，理论上不违反本层约束（ADR-018），但需在基准评测(benchmark)中确认模型无此倾向。

## 测试要点

- 用假大语言模型(LLM)响应离线测试：合法标识(ID)集合通过；越界标识(ID)、超数量返回触发重试(Retry)；两次非法上抛人工介入(HITL)。
- 触发条件：确定性可解情形不调用大语言模型(LLM)（零调用验证）。
- 决策记录完整性（输入、返回、keep/drop）可断言。
