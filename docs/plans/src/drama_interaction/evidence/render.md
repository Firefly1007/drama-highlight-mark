# evidence/render.py 内容计划

本模块把一条专家分支可见的证据渲染为可复制引用的时间线文本。

## 职责与边界

- 将基线 EvidenceDocument 与本分支 DerivedObservation 组合为提示词使用的 evidence_timeline。
- 显示 T<n>、O<n>、D<n> 标识和真实时间范围，使模型只需复制标识即可锚定证据。
- 不修改证据、不调用模型、不计算最终互动时间，也不跨分支合并派生证据。

## 输入、输出与接口

- 输入为基线证据、单个 specialist_type 对应的派生观察及 min_reported_gap_ms。
- 输出为按 start_ms 升序的纯文本时间线。
- 台词、观察和派生观察的标签必须逐字等于其 id；未被证据覆盖且达到阈值的区间输出未覆盖行。

## 依赖与消费者

- 依赖 schemas/evidence 和 config 的未覆盖阈值。
- specialists/base 用渲染结果组装提示词；scheduling/semantic 可复用局部渲染结果。

## 目标实现要求

- 每条证据只渲染一次；观察完全落在某台词跨度内时以缩进形式附在该台词下。
- 观察或派生观察与父台词跨度不同，或不被完整包含时，保留自己的时间范围并独立成行。
- 时间线必须覆盖从 0 到 episode_duration_ms 的可见证据与可报告空白，不能隐式重排或去重。
- 只合并基线与当前分支的派生证据；其他四条专家分支的 D<n> 绝不可见。

## 失败与边界情形

- 输入未通过证据结构校验、派生标识重复或派生项不属于当前分支时失败。
- 小于 min_reported_gap_ms 的空白不输出，避免把无法容纳互动的细缝交给模型。
- 文本格式、空白阈值和展示细节的未冻结部分只维护在 [PROGRESS](../../../../PROGRESS.md)。

## 验证

- 断言所有 T<n>、O<n>、D<n> 标签可被逐字复制回数据结构。
- 覆盖排序、嵌套、未覆盖区间、边界相接和空基线文档。
- 覆盖 A 分支派生条目不会出现在 B 分支渲染中。
- 对同一输入断言渲染结果稳定且不修改原对象。
