# 短剧即时互动生成工作流 V2 — 产品需求文档（Product Requirements Document, PRD）

本文只定义 V2 的产品目标、互动行为和验收标准。技术实现与取舍见 [架构决策记录（ADR）](drama-interaction-v2-ADR.md)，后端消费的 JSON 以 [输出契约](schema.md) 为准，实际完成度见 [当前进度](PROGRESS.md)。

## 1. 产品定位

V2 是一个面向单集短剧的离线互动点标注/生成引擎：根据本集已呈现的内容，为后端输出一组适时、可参与且不打断观看的即时互动配置。

V2 的目标是让五类互动直接从本集内容中发现机会，而不是先依赖“高光”筛选。它交付互动配置，不交付播放器、用户体系、内容运营服务或剧情生成能力。

## 2. 范围

### 包含

- 按单集生成互动配置；一集可以没有某一种互动，也不要求五类互动齐全。
- 固定支持五类互动：`emotion_button`、`repeat_keyline`、`instant_vote`、`deferred_vote`、`side_comment`。
- 为每项互动给出可展示的时间、持续时间和类型载荷，使后端无需参与生成判断即可消费。
- 对同一集的互动进行整体取舍，避免重复、冲突、过密或超出单集预算的展示。

### 不包含

- 前端播放器、业务服务、业务数据库、账号体系和评论区。
- `episode_comment`、`scene_bookmark`、`heatmap_bar` 等其他互动形态。
- 剧情分支、人工智能生成内容（AIGC）分支内容和跨集剧情续写。
- 跨集记忆、跨集摘要或新增的上游内容提取能力。

## 3. 五类互动

| 类型 | 产品行为 | 适用时机 | 核心价值 |
| --- | --- | --- | --- |
| `emotion_button` | 播放中展示可点击的情绪按钮，可附带短文案或预设弹幕。 | 爽点、笑点、打脸、危险、甜宠等即时情绪节点。 | 让用户低成本表达情绪，不中断观看。 |
| `repeat_keyline` | 邀请用户复述或接住一条关键台词。 | 名台词、角色放话、反转前后。 | 让用户参与剧情节奏，而不只是表态。 |
| `instant_vote` | 展示二选一投票，用户投完即可看到即时结果。 | 存在真实分歧的站队、真假或立场判断。 | 制造轻量的站队感。 |
| `deferred_vote` | 先让用户对悬念或预测投票，后随剧情揭晓结果。 | 身份悬念、剧情预测、真假判断。 | 把用户的选择与后续剧情结果连接起来。 |
| `side_comment` | 在剧情节点展示一句短吐槽、短评或提醒。 | 有明显讨论、反差或情绪价值的片段。 | 形成“剧情嘴替”的记忆点。 |

## 4. 互动行为规则

### 内容与时机

- 每项互动的事件、动作、关系、因果和答案必须建立在本集已呈现的内容上；剧集简介和角色表可以作为辅助上下文，用于辨认人名、关系和设定，但不能替代当前剧情事实，也不能单独触发互动。
- 不足以安全判断时宁可不生成，也不能编造台词、剧情事实、答案或揭晓结果。
- 互动应放在用户能够理解并参与的时机；任意两个最终互动的展示区间不得重叠。
- 单集内的数量、间隔和同类冷却由整体调度控制，避免互动过密而损害观看体验。

### 类型专属规则

- `emotion_button` 只用于明确的即时情绪表达，按钮含义必须与剧情匹配。
- `repeat_keyline` 应复用本集实际出现且值得跟读的关键台词，不得虚构“名句”。
- `instant_vote` 必须是恰好两个互斥、可理解的选项；不提供中立或无意义选项。
- `deferred_vote` 必须是本集后续能够验证的悬念或预测；提供两个至四个互斥选项，不能在提问时泄露答案。
- `side_comment` 必须简短、贴合当前剧情且不剧透；它表达的是轻量评论，不替代用户评论区。

## 5. 成功标准

V2 第一阶段完成后，应满足以下可验收结果：

1. 对一集输入内容，系统能够输出零到多条五类互动配置，且不出现范围外类型。
2. 每条互动都有可追溯的本集内容依据，类型、文案、选项和揭晓语义与当前剧情相符，不凭空补造剧情或泄露未来信息。
3. 输出中的互动在单集层面不存在重复、展示区间重叠、过密或超预算的最终展示。
4. `instant_vote` 与 `deferred_vote` 的选项数量及互动语义符合本文件规则；延迟揭晓投票在剧情可验证后再揭晓。
5. 最终输出可被后端按 [输出契约](schema.md) 直接解析；接口只使用五个固定的字符串 `type` 值。
6. 对代表性样集进行人工复核时，审核者能判断每条保留互动的内容依据、类型适配性和展示时机，并能区分“应省略”与“生成失败”。
